# 🛍️ Myshop - E-Commerce Web Application

A modern and responsive e-commerce web application built using HTML5, CSS3, and JavaScript. This project is designed to provide a smooth online shopping user interface experience.

## ✨ Features
- **Responsive Design:** Optimized for various screen sizes (Mobile, Tablet, Desktop).
- **Interactive UI:** Dynamic product display and user-friendly navigation using JavaScript.
- **Modern Styling:** Clean and attractive layout built with CSS3.

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Version Control:** Git & GitHub
- **Deployment:** GitHub Pages
